4️⃣ NDC深度：行业正在发生的变革

▸ NDC是什么：IATA制定、基于XML的数据标准，让航司绕过传统GDS的旧式票价框架（EDIFACT+ATPCO），直接向渠道（代理/OTA/差旅公司）销售「票价+附加服务」（行李、选座、餐食），自己掌握定价权和客户数据。核心模型从「库存+计价」变为 Offer（报价单）+ Order（订单）。
对比项传统GDS分销NDC分销
内容来源航司提交ATPCO→GDS统一分发航司API实时动态报价
售卖内容基本只有裸票价票价+附加服务打包(Offer)
定价权航司发布、渠道一致航司可对渠道差异化定价
旅客数据渠道掌握航司拿回数据
对代理一套系统查全网需逐家接入或经聚合商
▸ 航司现状：英航BA、汉莎LH集团、法荷航AF-KLM、新航SQ、澳航QF、美联航UA、达美DL等均已上线NDC。标志性事件：美航AA在2023年激进推进NDC，把部分票价内容撤出传统GDS，引发行业震动；汉莎LH早在2015年就对GDS出票收取每张约16欧元的「分销费DCC」。理解这两个案例，面试谈NDC就有血有肉。
▸ 聚合商 Aggregator：Travelfusion、Duffel、Verteil、Dohop等，帮代理一站式接入多家航司的NDC内容——代理不必逐一对接。快速切入NDC用聚合商，长期规模大再考虑直连自研。
💡 面试金句：NDC不是取代GDS，而是新增一条管道。代理的核心竞争力变成「谁能更快整合更多管道的内容」——多管道采价、比价、聚合能力。

5️⃣ ATPCO运价规则：定价的底层逻辑

▸ 税费构成：票价之外还有税项——YQ/YR=燃油附加费，XT=其他税种合计（机场税、安检税、离境税等）。报价时「票价+税费=总价」，税费同样影响竞争力。
▸ 运价构建术语：NUC中性货币单位（全球统一计价单位）、ROE汇率折算、MPM最大允许里程、HIP中间较高点检查、BHC回程检查、CTM环程最低价——国际联运票价的计价骨架。
💡 私价供应链逻辑（面试常考）：大代理向航司谈CAT35私价→比公布价低→低价冲量→销量达标拿「后返」→形成「私价+后返」的供应链模式。这就是为什么大代理能持续比小代理便宜——他们赚的是供应链的钱，不是单张票的差价。

💡 看懂这张表，你就理解了岗位JD里「P&L负责」的含义：
净收入 = GMV × (1 − 退票率)；毛利 = 净收入 − GMV × 采购成本率；净利 = 毛利 − 固定费用。
试着把采购成本率从 96% 调到 95%——毛利直接翻倍。这就是为什么「供应链优化」是负责人的第一杠杆。再把退票率调高 5 个点——利润几乎被吃光，这就是为什么「退票率」是风控核心指标。
国际机票毛利率通常只有 2%-5%：高流水、薄利润，任何浪费（盗刷、汇率、退票失控）都会被无限放大。
📝 自测题（先自己算，再点开答案）

某月 GMV 3000 万元，采购成本率 95%，退票率 3%，固定费用 25 万元。请问毛利和净利各是多少？毛利率约多少？

✅ 净收入 = 3000 × (1 − 3%) = 2910 万元
采购成本 = 3000 × 95% = 2850 万元
毛利 = 2910 − 2850 = 60 万元，毛利率 ≈ 60 ÷ 2910 ≈ 2.06%
净利 = 60 − 25 = 35 万元
结论：3000 万的流水最后只赚 35 万——这就是这个行业的真相，也是面试时谈「经营」的底气。

2️⃣ 退改签计算器 每天都会用到的实操计算

💡 计算公式：
自愿退票：应退金额 = 原票价 − 退票费（若退票费高于票价，实际退0）
自愿改签：应付 = 改签费 + max(0, 新票价 − 原票价)；新票价更低时，差额多数航司不退（部分可退到EMD杂费凭证）
非自愿（航班取消/时刻变更）：免费退票或免费改签，同航司改签更高舱位一般无需补差
📝 自测题（先自己算，再点开答案）

① 原票价3800，自愿退票，退票费800，退多少？ ② 原票价3800改签至4200，改签费600，付多少？ ③ 原票价4500改签至4000，改签费500，付多少？

✅ ① 应退 = 3800 − 800 = 3000 元
② 应付 = 600 + (4200 − 3800) = 1000 元
③ 应付 = 500 + 0 = 500 元，新票价低400元，差额不退（部分航司退到EMD）

▸ 什么是 ETERM？它和三大 GDS 什么关系？

一句话：eTerm 是订座系统的"窗口"。营业员在输入区敲指令、回车，主机在回显区返回结果——真实工作界面就是一个蓝底黑字终端，和本页 ⑥ 的模拟器长得一模一样。

ETERM 管什么：中国航司（国航CA/东航MU/南航CZ/海航HU…）的航班、国内航线、以及 BSP 国内结算的国际票。三大GDS管什么：境外航司在国际航线的分销。实际工作中两套系统并用——国际机票最常见的打法是"ETERM 订国内段 + GDS 订国际段"拼成一个行程，面试时说出这一点非常加分。

面试怎么答：问"你会订票吗"→ 答"会。ETERM 从 AV 查航班、SS 订座、NM/CT/TK 建 PNR、@ 封口拿记录编号、PAT:A/QTE 查运价、FN/FC/FP 输价、ETDZ 出票、DETR 验票，全流程都熟练；GDS 的 Amadeus/Galileo/Sabre 基本指令也会"。

▸ 界面长什么样？指令语法规则（核心！）

界面：上方是指令输入区（有 > 提示符），下方是系统回显区。所有操作 = 输入指令 → 回车 → 读回显。没有鼠标菜单，一切靠指令。

指令语法 6 条规则（背下来）：

1. 基本格式：指令:参数　参数之间用 / 分隔　例：AV:H/PEKPVG/20OCT 2. 城市用三字码（PEK=北京、PVG=上海浦东），航司用二字码（CA=国航） 3. 日期格式 DDMMM：20OCT=10月20日（JAN FEB MAR APR MAY JUN JUL AUG SEP OCT NOV DEC） 4. 大小写均可，习惯全部大写 5. 修改 PNR 后必须 @ 封口才生效；不想保存输 IG 忽略 6. 冒号后参数顺序不能乱、少一个 / 就会报 FORMAT（格式错误）

封口（End Transaction）指令 @，把本次修改保存进主机。不封口 = 没保存！

③ 指令模块详解 每个指令：格式 → 参数 → 示例 → 输出解读

▸ 模块一：航班查询（AV / DS / SK / FF / DSG）

AV = Availability（可用座位查询）—— 最常用指令，没有之一。

格式说明
AV:PEKPVG查当天北京→上海全部直达航班（基础格式）
AV:H/PEKPVG/20OCTH=按起飞时刻排序显示，指定日期（最常用）
AV:RA/PEKPVG/20OCTRA=按到达时刻排序
AV:PEKPVG/20OCT/0900查指定时刻（9点）前后航班
AV:CA/PEKPVG只查国航（航司过滤）
AV:MU/PEKPVG/20OCT航司+日期组合过滤

怎么读 AV 回显（重点）：

AV:H/PEKPVG/20OCT 20OCT(SUN) PEKPVG 1 CA1501 PEKPVG 1105 1350 738 0^B S E F4 A4 P2 J2 C2 D2 Y9 B9 M9 H9 K9 L9 Q9 G9 V9 U9 S9 T9 E9 2 MU5183 PEKPVG 0800 1020 333 0 M F4 A2 P0 J9 C9 D9 Y9 B9 M9 H9 K9 L9 Q9 G9 V9 U9 S9 T9 E9 3 HU7605 PEKPVG 1930 2210 789 0 M F4 A4 P0 J2 C2 D2 Y9 B9 M9 H9 K9 L9 Q9 G9 V9 U9 S9 T9 E9

① 行号 1/2/3 = 订座时要引用的序号（SS 指令用）；② 航班号 CA1501 = 国航1501；③ 1105 1350 = 起飞11:05 落地13:50；④ 738 = 波音737-800机型；⑤ 第二行是舱位余座表：Y9 = Y舱有9个以上座位，P0 = P舱关舱无座；⑥ 0^B = 有餐食。

其他查询指令：

指令作用与示例
DS:PEKPVG/20OCT班期时刻：显示该航线哪些天有航班。回显里 1234567=每天都有；1357=周一/三/五/日
SK:PEKPVG最新时刻表（查询当前执行时刻）
FF:CA1501/20OCT航班经停信息：STOP:0 = 直飞；有经停会显示经停城市
DSG:C/PEKPVG按指定舱位（C舱）查班期

面试场景：客人要"10月20日北京飞上海下午的航班"→ AV:H/PEKPVG/20OCT，看行号、看 Y 舱余座，报价前先确认有座。

▸ 模块二：建立订座 PNR（SS / NM / CT / TK / OSI / RMK / @）

SS = Sell Seat（订座）。格式：SS:航班号/舱位/日期/航段/NN人数

SS:CA1501/Y/20OCT/PEKPVG/NN1 → 系统回显：1. CA1501 Y 20OCT PEKPVG RR1 1105 1350 738 E 0R

参数逐个拆：CA1501=航班号，Y=舱位（从AV的舱位行选一个有座的），20OCT=日期，PEKPVG=航段，NN1=申请1个座位（NN是行动代码，1是人数）。回显中 RR=直接确认、HK=已确认——看到这两个就是订上了。

指令格式与说明
SD:1查看第1个航段（订完立即 SD:1 检查舱位/日期/时刻对不对）
NM:1ZHANG/SAN姓名：人数+姓/名（姓在前！）。儿童加 CHD、婴儿加 INF（如 NM:1ZHANG/SANCHD）
CT:PEK/13800138000联系组：城市/电话（留旅客本人或代办人电话）
TK:TL/1200/20OCT/PEK出票时限：TL/时间/日期/城市。时限内不出票，座位可能被系统取消——面试高频考点
OSI:CA VIP航司备注（航司端可见，如备注特殊服务）
RMK:MP/内容内部备注（航司不可见，给自己人看）
@封口保存！系统返回 6 位记录编号（如 H4J8KL）

完整建立流程示例（可到模拟器亲手敲）：

> AV:H/PEKPVG/20OCT ← 查航班，记下行号1 > SS:CA1501/Y/20OCT/PEKPVG/NN1 ← 订Y舱1座 > NM:1ZHANG/SAN ← 姓名 > CT:PEK/13800138000 ← 电话 > TK:TL/1200/20OCT/PEK ← 出票时限 > @ ← 封口！ 记录编号: H4J8KL ← 记下编号，客人拿它出行

注意：NM/CT/TK 输入后系统不一定回显确认，以 @ 封口后 RT 提取看到的 PNR 内容为准。

▸ 模块三：提取与修改（RT / XE / XEP / IG / H / ML）
指令格式与说明
RT:H4J8KL按记录编号提取 PNR（最常用）。也可按姓名提取：RT:ZHANG/SAN/20OCT
XE:1取消第1个航段（改签第一步）。XE:PN=取消全部航段。取消后必须 @ 封口
XEP:1取消姓名项
IG忽略：撤销本次未封口的修改，PNR 恢复上次封口状态（改错了救回来）
H历史记录：显示谁、在什么时间、改了什么——售后纠纷查证利器
ML:H4J8KL名单显示（需授权，团队名单核对用）

改签标准流程（面试必背）：

RT:记录编号 → XE:旧航段号 → SS:新航班/新舱位/新日期/NN1 → @ 封口 例：RT:H4J8KL → XE:1 → SS:CA1501/B/21OCT/PEKPVG/NN1 → @

面试点：客人要改签，先 RT 提取确认原票状态，再取消旧段订新段，最后封口——"先取、再改、后封"六字诀。

▸ 模块四：运价（PAT:A / QTE / XS FSG / XS FSD / FN / FC / FP）
指令格式与说明
PAT:A查询运价：显示该航段各舱位票价（在 PNR 打开状态下输入）
QTE:CA1501/Y/PEKPVG精确计价：航班号/舱位/城市对 → 返回票价+税费+总价
XS FSG显示票价组（航线/舱位/票价一览）
XS FSD显示票价详情与规则条款（退改条件在这里查）
FN:FCNY1350.00/SCNY1350.00/C3.00/TCNY50.00CN/TCNY10.00YQ票价组输入（出票前必输）
FC:PEK CA PVG 1350.00Y CNY1350.00END票价计算行（运价横式）
FP:CASH,CNY付款方式：CASH=现金 CHECK=支票 CC=信用卡，CNY=人民币

FN 每个字段的含义（面试常考"FN 是什么"）：

FN:FCNY1350.00/SCNY1350.00/C3.00/TCNY50.00CN/TCNY10.00YQ └F=票价1350元 └S=实收1350元 └C=代理费率3% └T=税项：50元机场建设费(CN) + 10元燃油附加费(YQ)

QTE 输出解读：

QTE:CA1501/Y/PEKPVG 01 Y CNY1350.00 TAX: CNY50.00CN CNY10.00YQ TOTAL: CNY1410.00 → 票价1350 + 税60 = 总价1410 元（客人问"多少钱"报 TOTAL）

面试点：客人的支付金额 = 票价 + 税费总和（TOTAL），不是只看票价；代理利润来自航司给的代理费率（FN 里的 C 字段）。

▸ 模块五：出票与售后（ETDZ / DETR / TKTT / TRFD）

ETDZ = 电子客票出票。出票前检查清单（四确认）：

1. FN / FC / FP 三件套齐全 2. 在 TK 时限内（超时座位可能已取消） 3. 姓名与证件完全一致（错一个字都不能登机） 4. 舱位、日期、航段与客人确认的一致
指令格式与说明
ETDZ:1电子客票出票（PNR打开状态，数字1=打票机号）。成功后系统返回13位票号
DETR:TN/999-1234567890按票号查电子客票（TN=Ticket Number）；加 ,H 查历史版本
DETR:NI/110101199001011234按证件号（身份证）查票——客人票丢了先查这个
DETR:NM/ZHANG/SAN按姓名查票（显示该旅客名下全部客票）
TKTT:TN/999-1234567890查询客票状态
TRFD:AM/1/D退票：AM/航段号/D（需退票权限，手续费按运价规则 Cat16 计算）

客票状态码（DETR 回显最后一行，面试常考）：

状态含义状态含义
OPEN FOR USE客票有效可用USED已使用
REFUNDED已退票EXCHANGED已换开（改签后旧票作废换新票）
DETR:TN/999-1234567890 ISSUED BY: AIR CHINA ← 出票航司 ORG/DST: PEK/PVG ← 出发/目的地 NAME: ZHANG/SAN ← 旅客姓名 FLIGHT: CA1501 Y 20OCT PEKPVG 1105 1350 STATUS: OPEN FOR USE ← 状态：有效可用 ✔

面试场景：客人说"票查不到/不能登机"→ 先 DETR:NI/身份证号 查票号和状态；OPEN FOR USE 却登不了机 = 证件与姓名不符，REFUNDED = 已退票。

🌐 三大 GDS 系统实操

国际业务必备

GDS（全球分销系统）是国际机票的"基础设施"。三大系统：Amadeus（1A，全球份额第一）、Sabre（1S，美国第一）、Galileo（1G，Travelport 旗下）。国际机票团队日常就是"ETERM 出国内段 + GDS 出国际段"组合工作。本页给每个系统配了：完整指令表 + 真实订票流程仿真模拟器。

🔄 退改签与国际换开

票务核心 · 面试必考

出票只是开始——票务岗位 70% 的日常工作在退改签。本页从概念到实操全覆盖：改签（自愿变更）、退票（Refund）、国际换开（Reissue）、各航司规则框架、金额计算器，外加三套仿真终端实战。

⚠️ 所有规则与数字均为教学参考值（行业公开规则框架），真实业务以出票时运价规则（fare rules）为准——面试的正确答法永远是"以运价规则为准，按 Cat 16 条款执行"。

① 核心概念 先把行话说对

概念含义（面试高频）
自愿变更 (Voluntary)旅客自身原因改期/退票 → 按运价规则收手续费
非自愿变更 (Involuntary)航司原因（延误/取消/时刻变更）→ 免费改退，甚至可要求补偿
改签 (Change)改日期/航班；票价不变仅收手续费；票价变化则走换开
换开 (Reissue)原票作废换新票号，原票价值结转进新票（旧票状态 EXCHANGED）
退票 (Refund)按规则扣手续费后，余额退回原支付渠道（状态 REFUNDED）
Cat 16运价规则第16类条款 = 退改签罚则，所有手续费的依据都在这里
EMD电子多用途凭证：换开产生的残值/服务费出成 EMD 给旅客
ADM航司对代理的罚单（错退/错收/超时限出票等操作错误）——老票务谈 ADM 管控非常加分
No-show误机：旅客未乘机，多数航司 no-show 后退改费更高、部分票直接作废
客票有效期一般自出票日起 1 年；退票须在有效期内办理

② 改签实操 同舱改期 + 跨舱换开

▸ 改签完整流程与金额计算

ETERM 改签流程（六字诀：先取、再改、后封）：

RT 提取RT:H4J8KL
取消旧段XE:1
订新航段SS:航班/舱位/新日期/NN1
封口@
验票DETR 查状态

金额计算两条路：

① 同舱改期（票价不变）：只收改签手续费（如 CNY200），票号不变，改完 PNR 即生效 ② 跨舱/票价变化：必须换开——新票价 − 原票价 + 改签手续费 = 应收金额 例：原票1350 → 改B舱2430，手续费200 → 应收 2430−1350+200 = CNY1280

面试点："客人要改期怎么办"→ 先查原票状态（DETR）→ 查新航班（AV）→ 比价（PAT:A/QTE）→ 报价（差额+手续费）→ 客人确认后 RT→XE→SS→@。先报价再操作！

③ 退票实操 手续费梯度 + TRFD

▸ 退票流程、手续费逻辑与红线

退票流程：验票 → 查规则 → 算应退 → 退票 → 复核

验票DETR:TN/票号 查状态
查规则XS FSD 看 Cat16
算应退票价−退票手续费
执行退票TRFD:AM/1/D
复核DETR 显示 REFUNDED

手续费梯度逻辑（教学示意）：起飞前越早退越便宜，起飞后退最贵；舱位越高越宽松。

例（教学示意）： Y舱 起飞前24h以上免费退 → 24h内退10% → 起飞后20% H舱 起飞前24h以上退20% → 24h内退30% → 起飞后50% 特价E舱 不退不改（或只退税费）

红线（面试加分）：① 退票前必须确认是否非自愿（航变免费退，收错费会吃 ADM）；② no-show 后退票费率更高或不可退；③ 国际票退票周期长（需航司结算），要提前管理旅客预期；④ 已用部分航段的客票按"半程使用"规则计算残值。

④ 国际换开专题 Reissue · 票务天花板技能

▸ 什么是换开？何时必须换开？

换开（Reissue）= 原票作废、新票生成，原票价值（票价部分）结转进新票。换开后：旧票状态变 EXCHANGED，新票是全新 13 位票号，票面标注 EXCHANGED FROM 原票号。

何时必须换开（对照何时只需改 PNR）：

场景处理方式
同舱位改日期改 PNR 即可，票号不变（部分航司收手续费）
升舱/降舱、票价变化必须换开：补差价+手续费，出新票号
改航线（目的地变化）必须换开（原票价值可部分结转）
换航司一般需退旧票重开（部分联盟内可换开）
国际票改期（多数航司）换开：国际票普遍按 Reissue 处理
▸ 换开四要素 + 金额计算案例 + Amadeus 指令流

换开四要素（面试答这个结构直接封神）：

原票价值FO行：原票号+原票价
新票价FXP 重新计价
手续费Cat16 罚则
差额/残值补收 or 出EMD

核心公式：应收 = 新票价 − 原票价 + 换开手续费

案例1（补差）：原票4680改期，新票价5380，手续费200 → 应收 5380−4680+200 = CNY900 → 收钱后换开，出新票号 案例2（残值）：原票4680改到更低价航班，新票价3980，手续费200 → 3980−4680+200 = −500 → 应退 CNY500 → 出 EMD 凭证给旅客 案例3（特价票）：原票是特价E舱（不退不改）→ 换开不划算 → 建议退了税费重买

Amadeus 换开指令流（教学参考）：

RT2ABC3D（提取原PNR）→ XE1（取消旧段）→ SS1Y1（订新段）→ ET（封口） → FXP（新票价）→ FO125-1234567890PEK20OCT16/4680.00（输入原票价值FO行） → TTP/EXCH（换开出票）→ 新票号生成 → TWD 验证 EXCHANGED FROM

⚠️ 换开是票务中最容易吃 ADM 的操作：FO 行票号/金额录错、手续费算错、非自愿变更误收手续费——都会被航司开罚单。老票务经验：换开前先打印原票记录、双人复核 FO 行、留存报价沟通记录。
